# Examples

All fixtures here are **synthetic**: invented payee addresses, invented
company names, and a pinned date (2026-11-14). Nothing here pays real
money, names a real wallet, or calls any network.

- `brave-402.json` - a 402 response in the public Brave shape: amount
  `5000` base units USDC ($0.005), chain `eip155:8453`, EIP-3009
  (`extra.name` / `version`), one payment option. The `payTo` address is
  invented; the `asset` address is the public USDC contract on Base.
  `vendor` / `tool` / `host` fields are spendgate's own annotations so the
  file works without extra flags.
- `ledger-sample.jsonl` - a small hash-chained ledger generated by the
  real CLI (`record`) from this fixture: 3 ALLOW payments of $0.005 on
  2026-11-14, 1 DENY (denylist payee, $5.00), 1 REVIEW (lookalike payee).
  Try it with:
  `spendgate check --config examples/demo-policy.json --ledger examples/ledger-sample.jsonl`
  (exit 0 - a DENY or REVIEW line is the gate working, not a violation) and
  `spendgate report --ledger examples/ledger-sample.jsonl`.
- `demo-policy.json` - the demo policy used for the sample ledger: the
  `init` sample with the synthetic fixture payee in the allowlist and a
  synthetic denylist payee.
- `spendgate.json` is NOT shipped here: run `spendgate init` to scaffold
  it, then replace the placeholder allowlist payee with your real vendor
  address.
